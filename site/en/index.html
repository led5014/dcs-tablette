What DCS Tablette does

Live displays

The cockpit displays mirrored from DCS, with the buttons around their frame. A button stays pressed in the cockpit for as long as your finger stays down.

Redrawn panels

On the Hornet: touch UFC, IFEI, standby instruments and warning lights. On the F-16: the ICP keypad with the DED above it.

Instruments for any aircraft

Airspeed, attitude, altimeter, turn and slip, heading, vertical speed, G and RPM, in the cockpit's own units. Enough to keep your eyes outside, warbirds included.

Kneeboard

The mission, module and map pages and your own, sharp at any size, plus the DCS kneeboard, live.

Per-display settings

Brightness, contrast, sharpness, resolution, and filters: auto levels for a dark TGP, black and white, green, amber, night red.

Tablet or phone

The page follows the aircraft you fly and only offers the layouts that stay comfortable to touch on the screen in use, in portrait or landscape.

What you need

  • A Windows PC with DCS World.
  • A tablet or phone on the same Wi-Fi as the PC: an iPad on iPadOS 13 or newer (iPad Air 2, iPad mini 4, iPad 5th generation and later), an Android tablet or phone, or the browser of another PC.
  • Nothing else: no Python, no app on the tablet. The page opens in the browser.

The internet is used to install the virtual display, to look for a new version at launch and, once, to download the F-16 DED table. Nothing in flight.

Install in three steps

  1. Download the zip

    The latest release's zip holds the program and its installer.

  2. Extract it, then double-click Installer.bat

    Anywhere: the Downloads folder is fine. If Windows shows "Windows protected your PC": More info, then Run anyway. The program isn't signed; it is built from the code published on GitHub.

  3. Answer the window's questions

    It installs and places a virtual display (Virtual Display Driver, free), where DCS draws the cockpit displays, then installs the scripts in DCS, sets DCS to windowed and adds a DCS Tablette shortcut to the desktop. If a step fails, it says which one and what to do.

In flight

  • Launch DCS Tablette: its window shows the address to open on the tablet, such as http://192.168.x.x:8320. On first launch, allow the program on private networks.
  • Open the address on the tablet, then add it to the home screen to get it full screen.
  • Start DCS and a mission: the page builds itself for the aircraft you fly.

Updates install themselves at launch: verified download, settings kept. To uninstall: Settings → Apps → Installed apps → DCS Tablette.

Supported aircraft

Displays and buttons

F/A-18C Hornet, F-16C Viper, AH-64D Apache, OH-58D Kiowa, A-10C and A-10C II, AV-8B Harrier, F-15E Strike Eagle, JF-17 Thunder, Ka-50 Black Shark II and III.

Displays only

C-130J-30 Super Hercules (three HDDs), MiG-29A Fulcrum (the HDD, which repeats the HUD).

Instruments and kneeboard

Warbirds: P-51D, TF-51D, P-47D, F4U-1D, Spitfire IX, Mosquito, Bf 109 K-4, Fw 190 A-8 and D-9, I-16, Yak-52. Korea: F-86F, MiG-15bis. F-14, F-4E, Mirage 2000C, Mirage F1, F-5E, MiG-21bis, MiG-19P, AJS-37, L-39, C-101, MB-339, FC3. Helicopters: CH-47F, Mi-8MTV2, Mi-24P, UH-1H, SA342.

Any other aircraft gets the basic instruments and the kneeboard. Buttons on the F-16C, OH-58D, AV-8B, F-15E, JF-17 and Ka-50 still need confirming in flight: feedback on the Discord helps.

Multiplayer

  • DCS Tablette only writes to Saved Games\DCS, never to the DCS install folder: the servers' integrity check is not affected.
  • A press on the tablet does in the cockpit what a mouse click on the same button would.
  • The tablet script inside DCS only accepts the buttons shown, through an allowlist for each aircraft, and releases any button held for more than 5 seconds.
  • A server that forbids exporting your own aircraft's data turns the instruments off: the tablet tells you so.

Help and ideas

The L'atelier DCS OS Discord is free and French-speaking, English questions welcome: help in #aide, aircraft and feature requests in #idées, new releases in #annonces.

On the tablet, the status dot at the top left opens the diagnostics: what is missing and how to fix it. The full guide covers installation, screenshots, streaming and common problems.
